# Bungah Water Client

Frontend React application for Bungah Water Order and Delivery system.

## Setup

```bash
npm install
```

## Development

```bash
npm start
```

The app will run on http://localhost:3000

## Features

### Customer Pages
- `/` - Home page with phone number login and today's deliveries
- `/history` - View personal order history

### Admin Pages (Password: bw2026)
- `/bw` - Admin dashboard with order management
- `/bw/customers` - Customer management
- `/bw/orders` - Order management
- `/bw/revenue` - Revenue tracking

## API

This app connects to the backend API at http://localhost:3001
